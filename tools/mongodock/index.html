1 · Seed with batched bulkWrite

A lazy generator feeds bulkWrite({ batching: true }). Operations are grouped into batches and written through an async slot pool with bounded concurrency.

ASYNC SLOT POOL INSIDE
Invalid rows fail schema validation; the rest of their batch still succeeds.
BATCH TIMELINEWaiting for a run
const report = await db.bulkWrite({
  model: "PlaygroundItem",
  batching: true,
  operations: lazyInserts(),          // array, Iterable or AsyncIterable
  batchSize: 25,
  concurrency: 4,
  onBatch: (outcome) => emit(outcome), // streamed to this page live
});
